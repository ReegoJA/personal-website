# Working on this portfolio

Keep the static, dependency-free design unless a feature requires something more. Follow the linked Google conventions and `.editorconfig`. Keep each module focused and use text insertion for remote data.

For content edits, update `dist/index.html`. For visual changes, update `dist/styles.css` and `dist/interactions.css`. Keep planned work distinguishable from completed work, and add measurements only after checking them.

Run `npm test`. Check expandable entries, margin prompts and email copying, GitHub loading/error states, keyboard navigation, and narrow-screen layout. Ensure external links are clearly identified and placeholders remain empty until real outputs exist.

Update the README file map, credits, and dated history whenever files, dependencies, or behavior change. Record libraries, maintainers, licenses, and actual contributors, do not imply that paper authors contributed code.

Use concise commit messages formatted as lists of sentence fragments. Preserve actual dates and Git history. Do not fabricate authorship or completion records.


Do not include secret keys, personal source PDFs, local screenshots, or temporary credentials in commits.
